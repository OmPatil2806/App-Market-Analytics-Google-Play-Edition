# 📱 App-Market-Analytics — Google Play Edition

A complete data analysis and visualization project based on the Google Play Store dataset, featuring data cleaning, exploratory analysis, category insights, and an interactive Streamlit dashboard for dynamic exploration.

---

## 📊 Project Overview

This project provides an end-to-end analysis workflow covering:

- Data cleaning and preprocessing  
- Handling missing values and standardizing fields  
- Exploratory Data Analysis (EDA) with visualizations  
- App category comparisons and trends  
- Install, rating, and price insights  
- Correlation and distribution analysis  
- Exporting a fully cleaned dataset  
- Interactive Streamlit dashboard for real-time filtering  

The goal is to uncover meaningful patterns in the mobile app market and present them through clear visual insights.

---

## 📁 Dataset

The dataset includes:

- App name  
- Category  
- Rating  
- Reviews  
- Size  
- Installs  
- Type (Free/Paid)  
- Price  
- Content Rating  
- Genres  
- Version information  

A cleaned version of the dataset is generated:  
**`googleplaystore_cleaned.csv`**

## 🧼 Data Cleaning Steps

- Removed missing or invalid ratings  
- Filled missing categorical fields using mode  
- Standardized version fields  
- Converted size values (k → thousand, M → million)  
- Cleaned installs and price columns  
- Removed duplicates  
- Converted data types for analysis  

---

## 💻 Streamlit Dashboard

A dedicated dashboard allows users to:

- Filter apps by category, type, rating, or installs  
- Visualize distribution charts  
- Explore category trends interactively  
- View top-performing applications  
- Analyze free vs paid applications visually
